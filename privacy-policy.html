TAG-BOT collects your Discord user ID solely to remember whether you have seen the initial user notice. This is used only to improve your experience by preventing the notice from appearing repeatedly.

Your Discord ID is used only for the purpose of managing the user notice display. We do not collect, store, or process any other personal data.

8. Message Content Usage

This process is solely intended to improve the user experience by automating setup and is completely optional. Server owners can disable this behavior at any time.
